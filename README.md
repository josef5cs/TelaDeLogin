# Tela de Login
1- Através do Github Pages temos acesso apenas ao Front End da Tela de Login - Tela de lembrar senha - Cadastro de usuário
2- Para ter acesso ao banco de dados baixe o repositório, abra-o no Vscode.
3- Instale o json server usando o comando "npm install json-serve"
4- Abra o terminal do repositório de de o comando "npm run server"
5- Provavelmente o banco de dados estara acessovel através do endereço "http://localhost:3000/cadastros"
6- Agora na página lembrar senha e no cadastro de usuário você terá acessoa ao banco de dados para fazer qualquer tipo de alteração e realizar o login pelo Index.html
